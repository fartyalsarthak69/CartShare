## About The Project
CartShare is a frontend web application built as an internship project. It solves the problem of uncoordinated group shopping in shared living spaces by providing a real-time, shared virtual cart. 

## Features Implemented
* **Room-Based Access:** Users can join specific rooms using a custom code.
* **Real-Time Synchronization:** The cart updates instantly across different browser tabs using the Window Storage Event.
* **Activity Log:** Tracks and timestamps who added or removed specific items.
* **Printable Receipt:** Uses specific CSS print media queries to generate a clean, print-ready final receipt.
* **Responsive Design:** Fully functional and styled for both mobile and desktop screens using Bootstrap 5.
* **Data Persistence:** Uses the browser's LocalStorage to save cart data even if the page is refreshed.

## Technology Stack
* HTML5
* CSS3 & Bootstrap 5
* Vanilla JavaScript

## How to Run Locally
1. Download or clone this repository to your local machine.
2. Open the `CartShare` folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click anywhere in the code and select **"Open with Live Server"**.
5. The application will open in your default web browser.
